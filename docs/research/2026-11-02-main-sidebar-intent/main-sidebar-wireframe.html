Main + sidebar: “make the browser the main one”

The chosen board takes the big slot and every other board on the canvas moves into a sidebar, fitted to the window. On a wide window the sidebar sits to the right; on a tall one it sits below. One Ctrl+Z undoes it. The same arrangement is reached from the board menu, the Tidy picker, Jarvis and agents.

Where it lives

  • Board menu (···): Make main board, for that board.
  • Tidy picker: Main + sidebar, third after By role and Fit to screen; it uses the selected board and is disabled with a hint when nothing is selected.
  • Jarvis: make_main_board (“make the browser the main one”).
  • Agents: tidy_canvas with primary now; arrange_main_board once the package ships.

Rules

  • Every board on the canvas joins, except workers docked in a swarm board.
  • Sidebar side: right on a wide window, below on a tall one (or a side the user names).
  • Terminals resize to their slot; browsers keep their device aspect; planning, kanban and file boards keep their size.
  • No toast on success. One Ctrl+Z restores the previous layout. Too crowded to read: the existing “too small to read” toast.
